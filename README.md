## 🛠️ Projects

* **Big-Horn-Tire-Website/** ⭐ — Multi-page website for an auto repair and tire company. Features dynamic location details, interactive team rosters, service pages, and testimonials carousel. Built with vanilla HTML, CSS, and JavaScript. — [Documentation](./Big-Horn-Tire-Website) · [Live Demo](https://big-horn-tire-website.onrender.com)
  
* **Independence-Square-Website/** ⭐ — Bilingual (EN/ES) site chronicling the history of Independence Square in Independence, Missouri, with an interactive business directory, tour listings, and pioneer-trail info. Built with vanilla HTML/CSS/JavaScript. — [Documentation](./Independence-Square-Website) · [Live Demo](https://independence-square-historic-information.onrender.com)
  
* **CoffeeShop-Website/** ⭐ — Modern and responsive website design for a local coffee shop featuring an interactive menu, photo gallery, location details, and business hours. Built with vanilla HTML, CSS, and JavaScript. — [Documentation](./CoffeeShop-Website) · [Live Demo](https://coffeeshop-web.onrender.com)
  
* **The-Local-Website/** ⭐ — Responsive web design featuring custom layouts, interactive sections, and dynamic components. Built with vanilla HTML, CSS, and JavaScript. — [Documentation](./The-Local-Website) · [Live Demo](https://the-local-website.onrender.com)
  
* **Padoga-Website/** ⭐ — Modern static website layout with responsive UI components and interactive elements. Built with vanilla HTML, CSS, and JavaScript. — [Documentation](./Padoga-Website) · [Live Demo](https://pagoda-website.onrender.com)

Each project folder contains its own README with setup and usage instructions. All projects in this repo are static sites — no build step required, just open `index.html` or serve the folder locally.
